# 0006 — AGPL-3.0

**Status:** accepted · **Date:** 2026-10-09

## Context

Turnia is open source from day one, and may later be offered as a paid hosted service (freemium per
pharmacy). Under a permissive licence, anyone could host a modified Turnia as a competing closed
service.

## Decision

Licensed under the **GNU Affero General Public License v3.0**. Anyone may use, study, modify and
self-host Turnia; whoever offers a modified version to users over a network must publish their
modifications under the same licence.

## Alternatives

- **MIT** (as quantic-agent) — maximum freedom, including closed commercial hosting of this code.
- **Source-available licences (BSL, FSL)** — not open source by the OSI definition, which contradicts
  design N6.

## Consequences

- Contributions are accepted under the same licence (inbound = outbound).
- Some companies avoid AGPL dependencies; Turnia is an application, not a library, so that matters
  little.
